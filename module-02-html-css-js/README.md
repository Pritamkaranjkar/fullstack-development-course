## Overview

This module teaches the frontend layer of a web app. You will learn how HTML gives pages structure, CSS gives them style and layout, and JavaScript adds behavior and data updates.

By the end of this module, you should be able to build a simple, responsive Task Manager UI and explain the ideas behind the browser DOM, CSS layout systems, and async data loading.

## Learning objectives

By the end of this module, you should be able to:

- explain the difference between HTML, CSS, and JavaScript
- write semantic HTML with accessible labels, headings, lists, links, images, tables, and forms
- use CSS selectors, the box model, Flexbox, and Grid to build layouts
- make a page responsive with media queries and mobile-first design
- use JavaScript variables, arrays, objects, functions, events, and DOM APIs
- fetch data with `fetch()` and `async/await`
- split logic into ES modules and describe the purpose of a reverse proxy

## Instructor reminder

If a student only remembers four ideas from this module, they should be:

1. semantic HTML makes content clearer for browsers, tools, and people
2. CSS layout is about controlling space and relationships between elements
3. JavaScript turns static HTML into interactive apps through the DOM and events
4. `fetch()` and `async/await` let the frontend load data without freezing the page
