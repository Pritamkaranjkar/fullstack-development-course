# Solution 9: Complete the Task Manager UI starter

## Goal

Finish the starter Task Manager UI and make it work as a small static app.

## How to run

```bash
cd module-02-html-css-js/solutions/09-complete-task-manager-ui-starter
python3 -m http.server 8011
```

Then open http://localhost:8011.

## What it does

- renders a task list
- adds a task from the form
- marks tasks complete
- deletes tasks
- shows counts for total, done, and open tasks
- responds to a clear-completed button

## Notes

This solution uses the same structure as the starter, but with all TODOs completed.
