# Exercise 1: Build a semantic profile page 🟢

## Goal

Create a simple profile page for a student or developer using semantic HTML.

## Steps

1. Create a page with a `header`, `nav`, and `main`.
2. Add a hero area with a heading, short intro paragraph, and a call-to-action link.
3. Add a `section` for skills and a `section` for experience.
4. Use a list for skills and an `article` for each experience item.
5. Add a `footer` with contact links.

## Done when

- The page uses semantic elements in meaningful places.
- The structure is easy to read in the browser.
- The page has at least one heading hierarchy and a link.

## Difficulty

🟢 Easy

## Time estimate

10-15 minutes

## Short explanation

Semantic tags give your page a clear structure. They help the browser and assistive technologies understand the content.

## Common wrong approach

Using only `div` tags for everything and skipping headings and labels. This makes the page harder to understand and less accessible.
