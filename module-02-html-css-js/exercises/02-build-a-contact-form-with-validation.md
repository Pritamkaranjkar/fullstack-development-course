# Exercise 2: Build a contact form with validation 🟡

## Goal

Build a small contact form with labels, required fields, and browser validation.

## Steps

1. Create a form with `name`, `email`, and `message` fields.
2. Add a `label` for each input.
3. Set `required` on the fields that must be filled.
4. Use `type="email"` for the email field.
5. Add a submit button.
6. Test what happens when a field is empty or the email format is invalid.

## Done when

- The browser blocks invalid submission with form validation.
- Each field has a label attached to the input.
- The form is easy to read and works on a phone-sized screen.

## Difficulty

🟡 Medium

## Time estimate

15-20 minutes

## Short explanation

Forms collect user input. Validation helps catch bad data before it reaches the server.

## Common wrong approach

Using placeholders instead of labels, or forgetting to connect labels to form fields. This hurts usability and accessibility.
