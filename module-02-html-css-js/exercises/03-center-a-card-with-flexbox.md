# Exercise 3: Center a card with Flexbox and make a navbar 🟢

## Goal

Create a centered card and a navigation bar using Flexbox.

## Steps

1. Create a page container with a centered card.
2. Use `display: flex` and `justify-content: center` to center content.
3. Add a navbar with links spaced across the width.
4. Use `align-items: center` so links and text line up.
5. Add a `gap` between nav items.

## Done when

- The card is centered on the screen.
- The navbar is aligned across the top.
- The layout works even when the window is resized.

## Difficulty

🟢 Easy

## Time estimate

10-15 minutes

## Short explanation

Flexbox makes spacing and alignment easier than writing many manual margins.

## Common wrong approach

Using a lot of fixed margins to push elements into place. This often breaks when the screen changes size.
