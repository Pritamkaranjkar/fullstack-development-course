# Exercise 9: Complete the Task Manager UI starter 🔴

## Goal

Finish the starter Task Manager UI and make it functional for a basic static app.

## Steps

1. Open the `starter/` files.
2. Add the missing markup and styles.
3. Connect the form to add a task.
4. Render tasks from mock data.
5. Add complete and delete buttons.
6. Make the layout responsive.

## Done when

- The page loads with a form and a task list.
- Users can add, complete, or delete a task.
- The UI works on desktop and mobile widths.

## Difficulty

🔴 Hard

## Time estimate

30-40 minutes

## Short explanation

This checkpoint combines everything you learned in the module: HTML structure, CSS layout, and JavaScript DOM events.

## Common wrong approach

Trying to do all logic in one giant function. Break the work into smaller pieces: render, add, complete, and delete.
