# Exercise 4: Recreate a 3-column layout with Grid, collapse to 1 column on mobile 🟡

## Goal

Build a 3-column layout using Grid and convert it to 1 column on smaller screens.

## Steps

1. Create a wrapper with three cards or sections.
2. Use `display: grid` and `grid-template-columns` to make three columns on desktop.
3. Add a media query that changes the layout to one column on mobile.
4. Add gap between cards.
5. Check the layout at desktop and mobile widths.

## Done when

- The desktop layout shows three columns.
- The mobile layout collapses to one column.
- Each card still reads clearly on a small screen.

## Difficulty

🟡 Medium

## Time estimate

15-20 minutes

## Short explanation

Grid is a good match when you need exact rows and columns. Media queries help adapt the layout to different screen widths.

## Common wrong approach

Using a desktop grid and expecting it to automatically respond to small screens without a media query.
