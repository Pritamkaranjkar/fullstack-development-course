# 00 - Setup (Do this before Module 1)

## Required software

| Tool | Download | Check with |
|------|----------|-----------|
| VS Code | https://code.visualstudio.com | open the app |
| Node.js (LTS) | https://nodejs.org | `node -v` |
| Git | https://git-scm.com | `git --version` |
| A modern browser (Chrome/Edge/Firefox) | - | open DevTools with `F12` |

## Recommended VS Code extensions
- ES7+ React/Redux Snippets
- Prettier - Code Formatter
- ESLint
- GitLens
- Thunder Client (API testing)

## Git first-time config
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

## Verify everything
```bash
node -v
npm -v
git --version
```
If all three print version numbers, you are ready.
