# Module 1 Solutions

This folder contains working answers for the exercises in this module.

## Files

- `01-verify-setup.md` - check that the environment is ready
- `02-inspect-network.md` - explain how to read browser network requests
- `03-first-server.js` - answer for the first server exercise
- `04-health-route.js` and `04-health-route.html` - answer for the health route exercise
- `05-git-project.md` - answer for the Git setup and commit exercise

## How to use

Open the exercise file, compare it to your own attempt, and read the short approach notes and wrong approach examples.
