# Solution 1: Verify Setup

## Working result

```bash
node -v
npm -v
git --version
```

If everything is installed, each command prints a version number. That means the environment is ready for the course.

## Approach

The goal is to check that the tools used in the course are present. We run the commands directly in the terminal, because they are installed on the machine and not in the browser.

## Common wrong approach

Do not try to run `node` from a browser or from an editor without opening the terminal. The browser cannot run your local project tools. You need the terminal to check and run them.
