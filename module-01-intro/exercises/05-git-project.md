# Exercise 5: Create a Small Project and Make Three Commits

Goal: create a fresh project folder, add a `.gitignore`, and make three meaningful commits.

## Steps

1. Create a new folder called `mini-project`.
2. Initialise Git with `git init`.
3. Create a `.gitignore` file and ignore `node_modules/`.
4. Add a `README.md` and one small script file.
5. Make the first commit with a message like `Initial project setup`.
6. Change the script or README and commit again.
7. Add a second meaningful change and commit again.
8. Run `git log --oneline` to review the history.

**Done when:** the project has three commits and the log shows each message clearly.

**Difficulty:** 🟡
**Time estimate:** 20 minutes
