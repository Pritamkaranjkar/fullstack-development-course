# Exercise 2: Inspect the Network (10 min)

1. Open any website (e.g. https://example.com) in Chrome.
2. Press `F12` and open the **Network** tab, then reload the page.
3. Click the first request and answer:
   - What is the **method**?
   - What is the **status code**?
   - What is the **Content-Type** of the response?
   - How many requests did the page make in total?
4. Open https://jsonplaceholder.typicode.com/todos/1 and repeat. How does the response differ from step 3?

**Bonus:** find a request with a status other than 200. What does it mean?
